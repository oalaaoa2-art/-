# Реактор ⚛

Бесплатный визуальный конструктор сайтов: выбираете готовый шаблон, правите текст прямо на странице, меняете шрифты и палитру — и забираете готовый `HTML`-файл. Без регистрации, аккаунтов и бэкенда.

При открытии показывается приветствие с описанием редактора и двумя путями: начать с пустой страницы или взять шаблон. Дальше это обычная пустая страница: блоки добавляются из панели слева, готовые шаблоны всегда открываются кнопкой «Шаблоны» у левого края холста, а вернуться к приветствию можно кнопкой «?» в шапке.

## Что умеет

- **Приветствие и пустая страница** — при заходе видно, что умеет редактор, а работать можно начать с чистого листа.
- **6 готовых шаблонов** — SaaS-лендинг, портфолио, кофейня, агентство, журнал и продуктовый лендинг. Каждый со своим текстом, палитрой и шрифтами.
- **25 шрифтов с кириллицей** (Google Fonts) — гротески, антиквы, акцидентные, рукописные и моноширинные. Отдельно для заголовков и основного текста.
- **Редактирование на месте** — кликаете по любому заголовку или абзацу на холсте и печатаете. Изменения сразу видны.
- **11 типов блоков** — шапка, первый экран, преимущества, текст с фото, галерея, цифры, тарифы, цитата, призыв, контакты, подвал. Блоки можно добавлять, дублировать, поднимать, опускать и удалять.
- **Панель свойств** — изображения по ссылке, пункты списков, тарифы, подписи, кнопки. Всё редактируется полями.
- **Стиль** — 10 палитр, ручные цвета фона/акцента/текста, скругление углов и ширина контента.
- **Превью под устройства** — десктоп, планшет и телефон с реальным пересчётом высоты.
- **Экспорт** — одна кнопка скачивает автономный `index.html` со встроенными стилями и подключёнными шрифтами. Его можно сразу открыть или загрузить на любой хостинг.
- **Автосохранение** в браузере и отмена/повтор изменений (Ctrl+Z-подобные кнопки в шапке).

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # проверка типов + продакшен-сборка в dist/
```

Нужен только Node.js 18+.

## Структура

```
src/
  App.tsx        — редактор: холст, панели, инспектор, история, экспорт
  render.ts      — генератор автономного HTML/CSS + скрипт правок внутри превью
  templates.ts   — шаблоны, фабрики блоков, палитры
  fonts.ts       — библиотека шрифтов и ссылки на Google Fonts
  types.ts       — типы документа, темы и блоков
  styles.css     — оформление самого редактора
```

Холст — это `iframe` с тем же HTML, который вы скачиваете, поэтому превью и экспорт совпадают один в один.
