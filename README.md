# Реактор ⚛

Бесплатный визуальный конструктор сайтов: собираете страницы из готовых секций, правите текст прямо на холсте, настраиваете размер и форму каждого блока, меняете шрифты и палитру — и забираете готовый `HTML`-файл. Без регистрации, аккаунтов и бэкенда.

При открытии показывается приветствие с описанием редактора и двумя путями: начать с пустой страницы или взять шаблон. Дальше это обычная пустая страница: блоки добавляются из панели слева, готовые шаблоны всегда открываются кнопкой «Шаблоны» у левого края холста, а вернуться к приветствию можно кнопкой «?» в шапке.

## Что умеет

- **Приветствие и пустая страница** — при заходе видно, что умеет редактор, а работать можно начать с чистого листа.
- **12 готовых шаблонов** — SaaS-лендинг, портфолио, кофейня, агентство, журнал, фитнес, клиника, юристы, онлайн-курс, событие и магазин. Каждый со своим текстом, палитрой и шрифтами.
- **25 шрифтов с кириллицей** (Google Fonts) — гротески, антиквы, акцидентные, рукописные и моноширинные. Отдельно для заголовков и основного текста, плюс 10 готовых пар.
- **Редактирование на месте** — кликаете по любому заголовку или абзацу на холсте и печатаете. Изменения сразу видны.
- **Многостраничные сайты** — вкладка «Страницы»: новая страница, переименование, дублирование, удаление и перетаскивание порядка. Шапка любого шаблона сама показывает ссылки на страницы, а в экспорте у каждой страницы свой адрес `#/slug`.
- **22 типа блоков** — шапка, плашка-объявление, первый экран, логотипы клиентов, преимущества, текст с фото, галерея, цифры, этапы, тарифы, цитата, отзывы, команда, хронология, таблица сравнения, вопросы и ответы, текстовый раздел, видео, подписка, призыв, контакты, подвал. Блоки добавляются, дублируются, переставляются перетаскиванием и удаляются.
- **Кураторская подборка дизайнов** — 10 проверенных сочетаний шаблона и стиля («Тихий SaaS», «Тёплая кофейня», «Редакционный журнал», «Дерзкое агентство» и другие) с описанием приёма и аудитории. Именно на них ориентируется ИИ.
- **ИИ-помощник в редакторе** — чат с бесплатной моделью без ключа (Pollinations, GPT-OSS 20B) и бесплатными тарифами Gemini, Groq и OpenRouter, плюс официальный DeepSeek и свой OpenAI-совместимый прокси. Помощник получает каталог и текущий документ и работает только с элементами библиотеки: конкретные блоки, шаблоны, стили, палитры и шрифты по точным id и названиям. Неизвестные элементы отклоняются и видны в отчёте о применённых действиях. Всё отменяется через Ctrl+Z.
- **Умный поиск по библиотеке** — поле в панели слева (или клавиша «/») ищет блоки, шаблоны, подборки, стили, палитры, шрифты и страницы по смыслу и синонимам: «цены» находит тарифы, «тёмный» — тёмные стили и подборки.
- **Размер и форма каждого блока** — ширина в процентах, максимальная ширина, минимальная высота, скругление углов, фон (панель, акцент или свой цвет), тень, выравнивание и отступы сверху/снизу. Узкий блок с фоном превращается в отдельное «окно».
- **Сетки и колонки** — для преимуществ, галереи, цифр и тарифов можно выбрать 2, 3, 4 колонки или автоматический режим.
- **Панель свойств** — изображения по ссылке, пункты списков, тарифы, подписи, кнопки. Всё редактируется полями.
- **Стиль** — 14 готовых стилей (палитра + шрифты + геометрия), 20 палитр, 10 пар шрифтов, ручные цвета фона/акцента/текста, скругление углов и ширина контента.
- **Превью под устройства** — десктоп, планшет и телефон с реальным пересчётом высоты.
- **Экспорт** — одна кнопка скачивает автономный `HTML` со встроенными стилями, подключёнными шрифтами и всеми страницами. Переходы между страницами работают по хешу без сервера.
- **Автосохранение** в браузере, отмена и повтор (кнопки в шапке или Ctrl+Z / Ctrl+Shift+Z), Delete удаляет выделенный блок.
- **Перенос старых черновиков** — сохранённый ранее одностраничный проект автоматически становится первой страницей.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # проверка типов + продакшен-сборка в dist/
```

Нужен только Node.js 18+.

## Структура

```
src/
  App.tsx        — редактор: холст, панели страниц и блоков, инспектор, история, экспорт, выполнение действий ИИ
  AiPanel.tsx    — чат ИИ-помощника и настройки подключения
  ai.ts          — провайдеры, промпт с каталогом и документом, запросы, разбор действий
  render.ts      — генератор автономного HTML/CSS, геометрия блоков, скрипт правок и переходов по страницам
  templates.ts   — шаблоны, фабрики блоков и страниц, палитры, стили, пары шрифтов
  fonts.ts       — библиотека шрифтов и ссылки на Google Fonts
  types.ts       — типы документа, страниц, темы и блоков
  styles.css     — оформление самого редактора
```

Холст — это `iframe` с тем же HTML, который вы скачиваете, поэтому превью и экспорт совпадают один в один. В редакторе показывается текущая страница, а при экспорте в файл попадают все страницы сразу.
